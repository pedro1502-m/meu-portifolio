Portfólio Web Interativo — UI/UX Dark Neon

Plataforma web desenvolvida do zero para reunir e demonstrar projetos práticos em desenvolvimento full-stack, modelagem de banco de dados e engenharia de software. O projeto foi construído priorizando alta performance, acessibilidade semântica e uma experiência de usuário (UX) fluida e moderna.

Design & Estética: Interface em Dark Mode baseada em gradientes neon (Ciano #38bdf8 e Violeta #8b5cf6), efeitos de glassmorphism (desfoque de fundo translúcido) e componentes gráficos customizados para cada aplicação.

Recursos Interativos: Animações de entrada dinâmica por rolagem (Scroll Reveal), menu de navegação responsivo, moldura circular de avatar animada e sistema de cópia rápida de e-mail via aviso toast.

Stack Tecnológica: HTML5 Semântico, CSS3 Avançado (Variáveis CSS, Flexbox, Grid, Animações @keyframes) e JavaScript Nativo ES6+ (DOM API, Intersection Observer API).
